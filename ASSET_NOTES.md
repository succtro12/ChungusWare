# Cosmetic asset record

The containment mascot used in this candidate is a modified user-supplied
Big Chungus/Bugs Bunny meme/character image. Its underlying character/artwork
is third-party; this project has no documented permission from Warner Bros.
It is not asserted to be original, licensed, public domain or free to redistribute.
The author explicitly chose to keep it for this candidate. No endorsement is
implied and this note grants no rights.

It is an OPTIONAL external PNG: copy-to-minecraft/ChungusWare/assets/containment.png.
Changing/removing it needs no DLL rebuild and affects no graphics feature.
Contract: PNG decoded by Windows WIC into RGBA; transparent background supported;
1..2048 pixels per dimension, maximum 8 MiB. Suggested aspect 300:332. Image is
contained/centered within the existing chamber. No name/character detection.
Assets load once per UI GPU-resource initialization; restart the game after
changing the PNG. No live updater exists. Missing/invalid files show an original
neutral crate and emit an OutputDebugString diagnostic.

For a rights-holder/platform request: remove/replace this PNG, update notices,
recheck package integrity/basic UI, and calculate new ZIP hashes. No renderer
logic, remote restore or circumvention mechanism is involved.

The Caca boom is the author's supplied quieter big boom.mp3, converted to PCM
WAV and retained, at explicit request, as embedded WAVE resource 101. This is
NOT the synthesized alternative and is NOT claimed original or licensed.
Its source/rights remain unverified. Changing it requires a resource-only rebuild
and revalidation. No loose sound is included in the runtime zip.

Display font: locally installed Windows Tahoma, selected by its exact face
name through Windows GDI and rasterized once into private memory. No Tahoma
font file, pre-rasterized Tahoma atlas, disk glyph cache or download is shipped.
If selection/rasterization fails, the following bundled OFL fallback is retained.

Fallback font: W95FA Regular, Version 1.002, regular-weight native-pixel glyph rasters for each existing text-size role, obtained from the
author distribution at https://www.dafont.com/w95fa.font. The font metadata
credits Alina Sava and FontsArena.com; SIL Open Font License 1.1. Full license accompanies the
derived embedded atlas. Font-source SHA256:
9e1ad53708307b2b68e06d43799b2267f6aec620dda972bc62753ad16ba50f2b.
The OTF is not shipped. The old atlas/glyph source is not shipped.

The atlas contains ONLY licensed glyph rasterization, the original geometric
crate placeholder and a white utility texel. No mascot pixels are embedded.
Bevels, gradients, cursor and status lights are code-drawn project primitives.
The static message corpus is project flavor text. No personal data is involved.
